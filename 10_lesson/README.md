# Документация проекта Lesson10

## Описание проекта

В проекте реализованы тесты для:

- Калькулятора (`CalculatorPage`)  
- Онлайн-магазина (`LoginPage`, `MainPage`, `CartPage`, `CheckoutPage`)  

Тесты размечены с помощью Allure:
- Шаги тестов (`@allure.step` или `with allure.step("...")`)  
- Декораторы тестов: `@allure.title`, `@allure.description`, `@allure.feature`, `@allure.severity`  

---

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: язык программирования для тестов  
2. **Selenium**: автоматизация браузера  
3. **Pytest**: фреймворк для тестов  
4. **Allure**: генерация отчетов  

### Форматирование кода

- Код оформлен по PEP 8  
- Методы и функции документированы с помощью docstrings  
- Все шаги тестов размечены `@allure.step` или `with allure.step("...")`

## Запуск тестов с формированием Allure-отчета
1. Открыть терминал в папке `10_lesson`  
2. Установить необходимые зависимости:

```bash
pip install -r requirements.txt

3. Запустить тесты и собрать результаты:
pytest --alluredir=./allure-results

- Результаты сохраняются в папку allure-results


Просмотр отчета Allure.
После прогона тестов выполнить:
allure serve ./allure-results

Откроется интерактивный отчет в браузере.
В отчете видны:
Название теста
Описание теста
Шаги теста
Результат выполнения


Примечания:
Некоторые тесты могут падать из-за внешних зависимостей (сайт, логины и т.д.)
Для выполнения задания важно показать, что отчет Allure создается и отображает шаги тестов
