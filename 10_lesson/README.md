ДОКУМЕНТАЦИЯ ПРОЕКТА LESSON 10

Описание проекта

В проекте реализованы автоматизированные тесты для:

- Калькулятора (CalculatorPage)

- Онлайн-магазина (LoginPage, MainPage, CartPage, CheckoutPage)

Тесты размечены с помощью Allure:

* Шаги тестов: @allure.step или with allure.step("...")

* Декораторы тестов:

  - @allure.title — название теста

  - @allure.description — описание теста

  - @allure.feature — функциональность, которую тест проверяет

  - @allure.severity — уровень критичности теста
  
---

ТЕХНОЛОГИИ И СИНТАКСИС

Проект использует:

1. Python — язык программирования для тестов

2. Selenium — автоматизация браузера

3. Pytest — фреймворк для тестов

4. Allure — генерация интерактивных отчетов

СТИЛЬ КОДА

- Соответствует PEP 8

- Методы и функции документированы docstrings

- Все шаги тестов размечены с помощью @allure.step или with allure.step("...")

ЗАПУСК ТЕСТОВ И ФОРМИРОВАНИЕ ALLURE-ОТЧЕТА

1. Открыть терминал в папке 10_lesson

2. Установить зависимости:
pip install -r requirements.txt

3. Запустить тесты и собрать результаты:
pytest --alluredir=./allure-results
  - Результаты сохраняются в папку allure-results.

4. Просмотр отчета Allure:
allure serve ./allure-results
   - Откроется интерактивный отчет в браузере, в котором видны:
     * Название теста
     * Описание теста
     * Шаги теста
     * Результат выполнения
