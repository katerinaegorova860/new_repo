ДОКУМЕНТАЦИЯ ПРОЕКТА CHITAI-GOROD UI + API

Описание проекта

В проекте реализованы автоматизированные тесты для:

- UI сценариев сайта интернет‑магазина «Читай‑город» (поиск книги, добавление в корзину, изменение количества, сортировка, переход в каталог)

- API корзины интернет‑магазина «Читай‑город» (добавление товара, проверка количества и суммы, удаление товара из корзины)

Тесты размечены:

- Pytest‑маркерами:
  - @pytest.mark.ui — UI‑тесты
  - @pytest.mark.api — API‑тесты

- Allure:
  - Шаги тестов: @allure.step или with allure.step("...")
  - Декораторы тестов:
    - @allure.title — название теста
    - @allure.description — описание теста
    - @allure.feature / @allure.story — функциональность/сценарий
    - @allure.severity — уровень критичности теста

---

ТЕХНОЛОГИИ И СИНТАКСИС

Проект использует:

1. Python — язык программирования для тестов
2. Selenium — автоматизация UI в браузере Chrome
3. Pytest — фреймворк для запуска тестов и работы с фикстурами/маркерами
4. Requests — HTTP‑клиент для API‑запросов
5. Allure + allure-pytest — генерация интерактивных отчетов по тестам [web:31][web:36]

СТИЛЬ КОДА

- Методы и функции документированы docstrings (там, где это необходимо)
- Основные шаги тестов размечены с помощью with allure.step("...") и Allure‑декораторов

ЗАПУСК ТЕСТОВ

1. Открыть терминал в папке project (корень проекта)

2. Установить зависимости:
pip install -r requirements.txt

3. Запуск всех тестов:
pytest

4. Запуск только UI‑тестов:
pytest -m "ui"

5. Запуск только API‑тестов:
pytest -m "api"


---

ЗАПУСК ТЕСТОВ С ALLURE-ОТЧЕТОМ

1. Запустить тесты и собрать результаты:
pytest --alluredir=./allure-results

   - Результаты сохраняются в папку allure-results

2. Просмотр отчета Allure:
allure serve ./allure-results

   - Откроется интерактивный отчет в браузере, в котором видны:
     * Название теста
     * Описание теста
     * Функциональность/история (feature/story)
     * Шаги теста
     * Результат выполнения
     * При необходимости — логи и вложения

ПРИМЕЧАНИЯ

- Токены и чувствительные данные рекомендуется выносить в переменные окружения или .env и не коммитить в открытый репозиторий.
- Некоторые тесты могут падать из‑за внешних зависимостей:
  - изменения на сайте chitai-gorod.ru
  - недоступность API
  - блокировки/ограничения по токенам или сессиям
- Перед запуском UI‑тестов необходимо, чтобы был установлен браузер Chrome и корректная версия ChromeDriver (может устанавливаться автоматически через webdriver-manager).
